# SAC-LSTM-EP

Core implementation accompanying the manuscript:

**Energy-Margin-Guided Adaptive Task Offloading with Hierarchical
Energy-Safety Control for UAV-Assisted Mobile Edge Computing**


## Included components

- SAC task-offloading policy
- LSTM finite-horizon UAV-energy prediction
- Predictive energy-margin calculation
- Hierarchical energy-safety control
- UAV-MEC simulation environment
- DDPG and NoPrediction controls
- Sanitized experiment configurations
